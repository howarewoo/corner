## Use Corner on a phone

Use **Home**, **Nutrition**, and **Training** in the bottom navigation. Nutrition returns to the section you last used. Open your profile shortcut for Settings. The training week and meal planner may scroll horizontally so each day remains readable.

Use your browser's text zoom if you need larger text. Check the selected date and units before saving, particularly when moving between a daily view and a weekly planner.

## Install from a secure application address

On a supported browser, open the actual Corner application over HTTPS. Use the browser's install option, or **Share → Add to Home Screen** on iPhone/iPad Safari, when available. Follow your browser's prompts. Installing this public guide does not install or sign you into the private product.

Availability and wording vary by browser and device. If there is no install option, use Corner in the browser. The installed window uses the same app origin and account flow; installation does not grant extra access.

## A network connection is required

Viewing your workspace, logging food or workouts, and saving all need a connection. Corner has no offline record cache, offline mutation queue, or background upload promise. An installed app is not an offline app.

If you see **You're offline**, reconnect and choose **Try again**. Do not assume changes entered while disconnected were queued. Reopen the relevant date and check the saved record before re-entering it.

## When a save does not finish

1. Keep the editor open and read the visible error.
2. Check your network connection. If Corner offers **Retry**, use it after connectivity returns.
3. If your session expired, sign in again. Unsaved drafts are not a backup.
4. Review the saved record before submitting the same action again, especially after an interrupted connection.
5. If the error says a record changed, reload the current version and review your intended correction rather than overwriting it with an old draft.

Recipe and direct-food forms retain entered values after a failed save, but closing, reloading, or signing out can discard unsaved work. A pressed button is not evidence of a completed save.

## Find a missing record

Check the signed-in account, selected day/week, filters, and whether you are looking at a plan or actual history. Planning a meal does not log it, and setting a weekly training pattern does not create a workout. Unrecorded values are not zeros.

If records came from a file, check that the [workspace import](/your-data/import-workspace) completed in the account you are viewing. Corner never copies another workspace based on email alone.

## Account, connection, and display help

- For codes and reset links, follow [account access help](/getting-started/account-access).
- For a client that still has access after sign-out, [revoke its connection](/connections#end-ongoing-access).
- For an empty grocery list, [check the selected week's meal plan](/nutrition/meal-planning#shop-from-the-selected-week).
- For wrong nutrition totals, [check per-serving nutrition and servings eaten](/nutrition/food-log#keep-per-serving-values-and-totals-distinct).
- For appearance, choose Light, Dark, or System in the product's theme picker. The guide keeps a readable light theme independently of your private app preference.

If a service problem continues, contact the support route supplied by the person who manages your instance. Include the action, time, and non-sensitive error text, and a request ID if one is shown. Never share passwords, codes, reset links, connection tokens, or a private export in a public report.
