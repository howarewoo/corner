## Create a recipe

1. Open **Recipes** and choose **New recipe**.
2. Enter a name, category, preparation and cooking times, and a description if useful.
3. Add ingredients using the form's format: one ingredient per line, with quantity, unit, ingredient, aisle, and an optional note separated by vertical bars.
4. Put each cooking step on a new line. Add storage or variation notes if useful.
5. Enter nutrition **per serving**, then choose **Save recipe**.

For example, a synthetic ingredient line is **60 | g | Oats | Pantry | dry weight**. Use consistent ingredient names and units so the grocery list can combine matching items meaningfully. Keep raw versus cooked weights clear in your notes.

## Check the serving definition

The recipe's nutrition is per serving. Selecting more servings scales the displayed ingredients and nutrition; it does not change the underlying recipe to a whole-batch total.

Synthetic example: one serving of an example bowl has 400 calories and 25 g protein. Selecting 1.5 servings gives 600 calories and 37.5 g protein. Those numbers illustrate multiplication, not a recommended meal.

## Reuse, edit, and download

Search the collection by recipe or ingredient, filter by category, and use Favorites for meals you return to. Open a saved recipe to edit it, add it to a plan, or choose **Download recipe (.txt)** for a readable text copy.

A recipe text download is not a workspace export. Use [Export workspace](/your-data) to take supported plans and records with you.

## Understand later changes

Editing a recipe does not rewrite the historical nutrition snapshot in food you already logged. A recipe used by a meal plan cannot be deleted until those planned uses are removed. Deleting a recipe does not delete historical food entries.
